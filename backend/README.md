# Projet Express MVC - Node.js

## Description
Petite API REST Node.js conteneurisée avec Docker, testée avec Jest et déployable via CI/CD.

## Installation
```bash
npm install
npm start
```

## Tests
```bash
npm test
```

## Docker
```bash
docker-compose up --build
```

## CI/CD
Pipeline automatique via GitHub Actions.
